honeybadger 문법정리

대상: Onboarding.ipynb, scripts/*.py 5개 파일. 제외: .git, venv, .venv.

예시는 원본 코드 재구성이 아니라 데이터사이언스 학회 면접 코드 테스트 대비용 단순 계산식과 결과값으로 정리했다.

pandas CSV 입출력, DataFrame/Series 생성, 선택, 집계, 시계열 수익률, 결측치, 표 변환
NumPy 난수, 배열 생성, 행렬곱, 차원 선택, broadcasting, 최댓값/최솟값 인덱스
보강 기준 AST 재점검으로 axis, broadcasting, to_numpy, 2차원 slicing까지 포함

누락 점검 결과

  • 메서드 체인만 보던 기존 정리에서 빠지기 쉬운 axis=1, 스칼라 broadcasting, pandas 라벨 정렬 broadcasting을 별도 항목으로 추가했다.
  • to_numpy(), values, ndarray slicing, fancy indexing, @ 행렬곱처럼 차원 제어와 관련된 문법을 NumPy/pandas 양쪽에 포함했다.
  • DatetimeIndex.year, Series.dt.strftime(), Timestamp.date()처럼 날짜 accessor 문법도 포함했다.
  • 문법 단위로 중복 제거했으며, 같은 문법의 반복 호출은 한 항목으로 묶었다.
